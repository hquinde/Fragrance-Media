# Stage 1 — Script Generation

1. Read `winners.md`, `failures.md`, and `fragrance-picks.md`.
2. Generate 3 scripts based on what worked and what didn't. If `fragrance-picks.md` has entries in the "To Feature" table, include at least one of those fragrances across the 3 scripts. Prioritize picks that fit naturally into a high-performing format.
3. Write the output to `output.md`.
4. Update `images/images.md` with the carousel topics and fragrance names from the scripts — e.g. `- Slide 1 (Fragrance Name):`
5. Move any used fragrance-picks entries from "To Feature" to "Already Used" in `fragrance-picks.md`.
