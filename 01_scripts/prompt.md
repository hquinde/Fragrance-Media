# Stage 1 — Script Generation Prompt

## Task

Read `context.md` and both reference files before writing anything.
Generate exactly 3 scripts in the format below.

## Rules

- 3 scripts per batch, each targeting a different vehicle type
- Check every title against Failures — hard block if it matches
- Exactly 6 slides: 1 title + 4 content + 1 CTA
- Exactly 1 sentence per content slide
- Each sentence under 20 words
- CTA: 4–6 words, tailored to topic + audience, always ends with "TrackAI."
- No "link in bio." No generic CTAs. No bullet points in body text.
- Tone: conversational, not corporate. Em dash for contrast. Specific numbers over vague claims.

## Output format

## Batch [N], Script [N]: [Title]

**Title slide:** [Title]

**Slide 1 — [Header]**
[One sentence.]

**Slide 2 — [Header]**
[One sentence.]

**Slide 3 — [Header]**
[One sentence.]

**Slide 4 — [Header]**
[One sentence.]

**CTA slide:** [4–6 word CTA ending in "TrackAI."]

---

Repeat for all 3 scripts. Run the quality checklist before outputting:
- [ ] 6 slides exactly
- [ ] 1 sentence per content slide
- [ ] No sentence over ~20 words
- [ ] CTA is 4–6 words, ends with "TrackAI."
